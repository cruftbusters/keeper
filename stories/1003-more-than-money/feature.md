# 1003: More than money

## Time

Keeper can keep time too. Just log time the same way you log money:

| credit | debit  | amount    |
| ------ | ------ | ---------- |
| effort | income | 40 hours   |
| income | assets | $ 5,000.00 |

| account | balance       |
| ------- | ------------- |
| effort  | ( 40 hours )  |
| income  | 40 hours      |
| income  | ( $ 5000.00 ) |
| assets  | $ 5,000.00    |
